About

생성 AI를 원리부터
실제 도구까지 살펴봅니다.

생성 AI란 무엇이며, 텍스트는 어떤 원리로 만들어지는가. Transformer와 토큰 예측이라는 기술적 토대 위에서 생성 AI는 스케일링 법칙을 따라 성장하고, 추론형 AI와 Agent로 진화해 왔습니다.

기본 개념부터 모델 내부의 작동 원리, 능력과 한계, 그리고 Agent 기반 시스템으로의 발전까지 실제 도구 비교와 함께 차근차근 살펴봅니다.

AI Journey

  4. 04
    AI

    Reasoning & Agent

    추론하고 도구를 활용하며 목표를 수행하는 시스템으로 진화합니다.
