파일과 주소 연결하기

저장소 파일접속 주소

각 폴더의 index.html은 그 폴더 주소로 접속할 때 보여줄 첫 화면입니다. 폴더를 추가할 때마다 새 저장소나 별도 서버를 만들 필요는 없습니다.

수정이 웹에 나타나는 순서

  1. HTML 파일 수정
  2. Commit으로 저장
  3. Pages 빌드·배포
  4. 브라우저 확인

Commit(커밋)은 변경 내용을 기록하는 저장 단위입니다. 배포는 저장한 파일을 실제 웹 주소에서 볼 수 있게 반영하는 과정입니다. 저장 직후와 배포 완료는 다릅니다.

주소가 다른 경우

이 저장소는 사용자 대표 사이트이므로 주소에 저장소 이름이 한 번 더 붙지 않습니다. 별도 프로젝트 저장소를 만들면 보통 https://mychoiand.github.io/저장소명/ 아래에 페이지가 만들어집니다. 회사 환경은 관리자가 정한 도메인과 접근 정책을 따릅니다.
